# 画像の置き場所

このフォルダに次の画像を置くと、アプリにイラストが出ます（コードは参照済みです）。

| ファイル名 | 使う場所 |
|---|---|
| `bg_meadow.jpg` | 画面全体の背景（草原とスライムのファンアート） |
| `wood_sign.png` | ホームのステータス枠（木の看板＋紙、透過） |
| `wood_plate.png` | タイトル帯（丸太のネームプレート、透過） |
| `wood_frame.png` | 枝の四角枠（予備、透過） |
| `wood_board.png` | セクションの枠（濃い木の板、透過） |
| `anime_bg.jpg` | ホーム上部の風景（浮遊城と草原） |
| `hero_slime.png` | ホーム上部：ターバンの主人公＋スライム（透過） |
| `panther.png` | ホーム上部：ヒョウの子（透過） |
| `slime.png` | タイトル横・スライムの案内役 |
| `king_slime.png` | 制覇10/50/100町の節目モーダル |
| `metal_slime.png` | メタルスライム級バッジ |

ファイルが無い間は、背景は緑の単色、枠は羊皮紙風の代替表示になるので、動作に支障はありません。
