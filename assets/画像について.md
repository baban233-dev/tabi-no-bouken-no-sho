# 画像の置き場所

このフォルダに次の画像を置くと、アプリにイラストが出ます（コードは参照済みです）。

| ファイル名 | 使う場所 |
|---|---|
| `anime_bg.jpg` | ホーム上部の風景（浮遊城と草原） |
| `hero_slime.png` | ホーム上部：ターバンの主人公＋スライム（透過） |
| `panther.png` | ホーム上部：ヒョウの子（透過） |
| `slime.png` | タイトル横・スライムの案内役 |
| `king_slime.png` | 制覇10/50/100町の節目モーダル |
| `metal_slime.png` | メタルスライム級バッジ |

ファイルが無い間は、風景はグラデーション、キャラは絵文字等で代替表示されるので、動作に支障はありません。
