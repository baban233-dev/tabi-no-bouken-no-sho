# 旅の冒険の書 — 企画書

作成：2026-11-13（企画段階。まだ作らない）
テーマ：ドラクエ風「冒険の書」

## 位置づけ

- 行ったあとの記録・評価のアプリ。「行きたいリスト」でも「精算」でもない
- 新規作成し、油屋（精算）・ほっかほっかカー（行きたいリスト）と連携する
- 精算は油屋に残し、行きたいリストはほっかほっかカーに残す。二重管理しない
- 土台は今までと同じ GAS＋スプレッドシート＋地図（Leaflet）の想定

## タイトルとドラクエ要素の役割分担

- タイトル：**「旅の冒険の書」**
- スライム＝案内役：トップに常駐。「制覇した町は○○、たからものは○個」と現状を教える。記録ゼロのときの案内もスライム
- キングスライム＝節目の祝い役：制覇した市区町村が10・50・100に届いたときに登場する特別演出
- 教会＝記録する（セーブ）：記録ボタンは「教会で きろくする」。保存すると「冒険の書に記録しました」
- ルイーダの酒場＝旅（クエスト）の管理：新しい旅を作る場所。一緒に行った人（パーティ）をここで決める。メンバーは かずや／ひとみ／れん／あやみ
- 宿屋＝道の駅・休憩スポット：場所カテゴリのアイコン
- 道具屋＝お土産店：場所カテゴリのアイコン
- お城＝景色・観光スポット：場所カテゴリのアイコン
- アイテム図鑑＝お土産コレクション：買ったお土産が図鑑に登録されていく
- 宝箱＝「たからもの」（また買う）：また買うと決めたお土産は宝箱入り。場所の「また行きたい」は金のピンで表す（役割は分ける）
- メタルスライム＝伝説級の印：評価が最高で、かつ「また買う」の記録に付く特別バッジ。めったに出ない
- ルーラ＝地図ジャンプ：都道府県・市区町村を選んで地図がその場所へ飛ぶボタン
- さくせん＝絞り込み・検索：条件で探すメニューの名前
- レベルと経験値：新しい市区町村を制覇すると経験値が大きく入り、レベルが上がる。場所の記録やお土産登録でも少し入る。トップのステータス欄に「Lv／制覇した町／集めたアイテム／たからもの」を表示
- ピンの絵は、パンどろぼうのときと同じくドット絵を自作する方向（宿屋・道具屋・お城・宝箱）

## 写真

- 旅ごとにGoogleフォト共有アルバム㇑つ（全部の写真の倉庫。枚数制限なし）
- 場所ごと：複数枚（目安10枚まで）
- お土産ごと：複数枚（目安5枚まで）
- カードと地図のピンでは1枚目をサムネイル、詳細では付けた写真を全部ギャラリー表示
- 写真をドライブへコピーしない（400GBの貯金箱は家族共有で容量が二重になるため）
- アルバムのリンクはスプレッドシートだけに置き、GitHubには書かない
- 記録を作るとき、その旅のアルバムの写真が一覧で出て、タップで複数選択できるようにするのが狙い。最初にタップした1枚が自動でサムネイルになる
- 注意：アルバムから一覧で選ぶ仕組みは未検証（ほっかほっかカーで確認できたのは「アルバムから写真のアドレスが取れる」ことまで）。作る段階で最初に検証し、ダメなら別の付け方に落とす

## 地図

### 探す用の地図（実用）

- 通常地図＋ドラクエ風の枠とピン（地図自体にセピアはかけない。店名や道路が読みやすい方を優先）
- 地図エンジンは Leaflet＋OpenStreetMap（無料、APIキー不要）
- ピンは場所ごとに1本。同じ場所でお土産を何個買ってもピンは1本で、タップすると中身が一覧で出る
- ピンはカテゴリ別アイコン。「また行きたい」の場所は金のピン
- 旅の中ではピンを日付順に点線でつないで番号を振る
- ルーラ（都道府県・市区町村へジャンプ）、さくせん（カテゴリ・たからものだけ・旅ごと、の絞り込み）付き
- ピンをタップすると写真つきミニカード → 場所の詳細へ

### 座標の取り方

- ほっかほっかカーの「調べる」方式。紹介URL欄＋「調べる」ボタンで、共有リンクの飛び先URLから店名を読み、住所と座標を自動で入れる
- 現場で「現在地で記録」ボタン（GPS案）は採用しない
- 取れなかったときは、今入っている名前を消さない（ほっかほっかカーの安全策と同じ）
- 新しいアプリを作る段階になったら、UrlFetchの権限承認が初回だけまた必要になる

### 制覇マップ（記録用）

- 探す用とは別の、ドラクエ風のワールドマップ。独立タブにはせずホームに統合し、制覇コーナー（数字）から開く形
- 訪れた場所の住所から市区町村を自動判定して、その市区町村だけを塗る
- 同じ市区町村に何か所行っても塗りは1つ（記録とピンは別々に残る）
- ズームできる形＋都道府県ごとの進み具合も数字で出す（例：東京都 3／62）
- 軽量化：ホームを開くたびに境界データを読み込まない。ホームの制覇コーナーは数字だけ（制覇した町の数、次のレベルまでのバー、都道府県ごとの進み具合）。制覇マップは「制覇マップを見る」をタップして初めて読み込む（遅延読み込み）。全国一括ではなく都道府県ごとに分割して読む。形はゲーム用に簡略化し、描画はCanvas方式

## 画面構成

- タブは4つ：**ホーム／地図／旅／図鑑**
- ホーム：ステータス窓＋スライムの案内＋冒険中の旅＋最近の記録＋制覇コーナー（数字だけ）
- 地図：探す用（通常地図＋ドラクエ風ピン、ルーラとさくせん付き）
- 旅：クエスト一覧 → 旅の詳細（日付順タイムライン＋点線ルート）
- 図鑑：お土産コレクション → お土産の詳細
- タブ外の画面：場所の詳細（写真ギャラリー／ミニ地図／評価／メモ／ここで買ったお土産一覧／編集・削除）、記録フォーム（教会：右下の「＋」から。「旅を選ぶ → 場所を入れる（URL＋調べる）→ 写真をアルバムから選ぶ → 評価とメモ → その場所のお土産も続けて登録」。場所とお土産を別々に入力させない）、旅の作成（酒場：旅の名前・日付・パーティ・種類（家族旅行／出張／日帰り）・アルバムのリンク）
- タイトル画面で毎回止まる形にはしない（開いたらすぐホーム。実用優先）

## 連携の流れ

- 大原則：**既存アプリには一切手を入れない。冒険の書が読みに行く（読み取り専用）**
- 初回に、冒険の書へ「他のシートを読む権限」の承認が1回だけ要る

### 油屋から

- 油屋の「お土産内訳」シートで種別＝購入の行をチェック（予算の行は対象外）
- まだ取り込んでいない行を「あずかり所」の候補に入れる（品名・金額・宛先・出張先・日付）
- ホームでスライムが「あずかり所に ○件あるよ」と知らせる
- 候補を開いて仕上げるのが正式登録。油屋のデータには「買った場所」がないので、ここで場所（URL＋調べる）・写真（旅のアルバムから）・評価・たからものを足して、図鑑に登録する
- 出張そのものも、出張一覧から「クエストの下書き」として候補に入れる（名前・日付・出張先）。すでに手で作った旅と日付・行き先が近ければ、新規にせず「結びつける？」と聞く
- 持ってこないもの：立替・自腹の精算データ、ステータス、お金の合計。精算は油屋が正本のまま

### ほっかほっかカーから

- 「行った」になった行き先だけをチェック（「行きたい」は持ってこない）
- 住所・座標・カテゴリ・行った日・行ったメモ・行き先ごとのアルバムまで揃っているので、ほぼ完成形の「場所の候補」としてあずかり所に入る
- 仕上げでやるのは、どの旅（クエスト）に属させるか。同じ行った日の行き先は「○月○日のおでかけ」として旅の下書きも一緒に提案する
- 場所に専用アルバムがある場合はそのまま使う。ない場合は旅のアルバムから選ぶ（両対応）

### 共通のルール

- タイミング：あずかり所を開いたときに調べに行く（裏で勝手に定期実行はしない）
- 重複防止：相手の行ごとにキーを記録して、二度取り込みしない。「いらない」と捨てた候補もキーを残して再表示しない
- 正式登録したら冒険の書が正本。その後に相手側を直しても、冒険の書の記録は変わらない。お金の正本は油屋、思い出の正本は冒険の書
- 逆向き（冒険の書 → 相手）への書き込みは、初版ではなし

## 記録する項目

### 場所（スポット）

- 名前／カテゴリ／住所・座標・市区町村（「調べる」で自動）／紹介URL
- カテゴリは7つ：道の駅（宿屋ピン）・お土産店（道具屋）・食堂／カフェ・観光／景色（お城）・温泉・宿泊・その他
- 行った日／どの旅か／一緒に行った人
- 評価／メモ／写真（複数枚）
- 同じ場所に再訪したら、記録は「訪問ごと」に足し、地図のピンは1本にまとめる。制覇の塗りも1回のまま

### お土産（アイテム）

- 品名／カテゴリ（お菓子・食品・飲み物・調味料・工芸品／雑貨・その他）
- 買った場所（場所にリンク）／買った日／金額（参考表示のみ）
- 誰用か（家用・妻の実家用・職場など。油屋から来た候補は自動で入る）
- 評価／誰が喜んだか（かずや・ひとみ・れん・あやみから選ぶ）／メモ／写真（複数枚）

### 旅（クエスト）

- 名前／種類（家族旅行・出張・日帰り）／期間／パーティ／アルバムのリンク／表紙写真／メモ

### 評価

- おすすめ度は★3段階
- 「また行きたい」（場所）「また買う」（お土産）は別フラグ
- ★3＋「また買う／また行きたい」でメタルスライム（伝説級）バッジ

## 技術面の注意（家族リストで踏んだ事故の教訓）

- 起動処理はページの読み込み完了（window.onload）を待たない（重い画像の読み込み待ちでアプリ全体が起動しなくなる事故があった）
- 外部ライブラリ（Leaflet等）の読み込み失敗が、一覧表示などアプリ全体を道連れに止めない作りにする
- 重いデータ（写真・境界データ）は最初に読み込まず、必要な画面を開いたときに後読みする
