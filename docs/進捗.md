### 2. 地図ライブラリ（Leaflet）読み込み失敗（対応中）
- 現象: 地図タブで「地図ライブラリの読み込みに失敗しました ネット環境を確認してください」
- 意味: `typeof L === 'undefined'`（Leafletのスクリプトが読み込まれていない）
- 可能原因:
  - htmlpreview.github.io 経由で外部CDNがブロック/遅延される
  - 使用CDN（jsDelivr / unpkg）へのアクセス不可
  - スクリプト読み込み前に初期化が走った
- 次の修正方針:
  - 複数CDNフォールバック
  - 動的読み込み + リトライ
  - または GitHub Pages でホストして htmlpreview を介さない
