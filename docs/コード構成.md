# コード構成（引き継ぎ用）

## 本番の動作ファイル（GitHub Pages）

| ファイル | 役割 |
|---------|------|
| `index.html` | 画面構造（4タブ・記録フォーム・旅作成・詳細モーダル・お土産編集モーダル） |
| `app.css` | ドラクエ風スタイル |
| `app.js` | タブ・記録・localStorage・地図・ルート・フィルタ・場所/お土産の詳細・編集・削除 |

確認URL: https://baban233-dev.github.io/tabi-no-bouken-no-sho/

## データ

- localStorage キー: `tabiBoukenNoSho_v1`
- 形式: `{ trips, places, items, exp, milestone }`（milestone はキングスライム表示済みの最大値）
- trips: `{ id, name, date, endDate, type, party[], album, note }`（date 以外はフェーズ8で追加）
- places: `{ id, tripId, name, cat, lat, lng, stars, wantAgain, note, date, pref, city, address, url, photos[], createdAt }`（date〜photos はフェーズ10で追加）
- items: `{ id, name, placeId, placeName, treasure, cat, price, forWhom, stars, note, photos[], createdAt }`（cat〜note はフェーズ7、photos はフェーズ10で追加。旧データは未設定のまま読める）
- 画像: `assets/slime.png`（案内役・タイトル）/ `assets/king_slime.png`（節目モーダル）/ `assets/metal_slime.png`（バッジ）。コードは参照済みで、ファイルが無い場合は絵文字にフォールバックする。本人が assets へアップロードする

## 技術メモ

- Leafletは静的 `<script src>` ではなく、複数CDNフォールバックの動的読み込み
- `window.onload` は使わない
- 地図タブ開時に遅延初期化 + `invalidateSize`
- 緯度経度空欄時は横浜付近に仮置き
- 場所詳細・編集・削除はすべて `app.js` 内（detail.js は使わない）
- 既存アプリ（油屋・ほっかほっかカー）には手を入れない

## 古いファイル

- `src/` 配下はフェーズ1時の残源（Pagesでは使わない）
- `detail.js` はフェーズ4で統合したため不要（残っていても読み込まない）
- 最新の動作確認は常にルートの3ファイルを見る
