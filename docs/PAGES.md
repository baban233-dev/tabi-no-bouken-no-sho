# GitHub Pages の有効化（1回だけ）

安定した確認用URLにするため、GitHub Pages を有効にしてください。

## 手順（スマホでも可）

1. リポジトリを開く: https://github.com/baban233-dev/tabi-no-bouken-no-sho
2. **Settings**（設定）を開く
3. 左メニューの **Pages**
4. **Build and deployment** → **Source** で  
   **Deploy from a branch** を選ぶ
5. Branch: **main** / Folder: **/ (root)** → **Save**

数分待つと、次のURLで開きます。

**https://baban233-dev.github.io/tabi-no-bouken-no-sho/**

（初回は 404 になることがあります。1〜3分待って再読み込みしてください）

## ファイル

- ルートの `index.html` が Pages で公開されます
- 中身は `src/preview.html` と同じです
