# 旅の冒険の書（Tabi no Bouken no Sho）

ドラゴンクエスト風の「行ったあとの記録・評価アプリ」。

精算（油屋）と行きたいリスト（ほっかほっかカー）とは連携するが、二重管理しない。

## 現在の状態（2026-11-13）

- **フェーズ0：準備完了**
- 企画書を収録
- リポジトリ作成（公開）
- 次はフェーズ1（骨格づくり）から

## 目的

1. GitHub上で静的プロトタイプを作る（他のAIへの引き継ぎやすくするため）
2. ある程度完成したら GAS + スプレッドシート に移植
3. 本番環境で動作確認

完成後はリポジトリを private に切り替える予定。

## 他のAIへの引き継ぎ方法

1. このリポジトリを先に読む
2. `docs/企画書.md` を必ず確認
3. `docs/進捗.md`（後で作成）で現在の進捗を確認
4. 次にやるべきことを`docs/次にやること.md`で確認
5. コードを変更したら進捗を更新する

## 技術スタック（予定）

- **プロトタイプ段**: 純粋的HTML/CSS/JS（GitHub Pagesで確認可能に）
- **本番**: Google Apps Script + スプレッドシート + Leaflet + OpenStreetMap
- 地図: Leaflet（APIキー不要）
- 写真: Googleフォト共有アルバム（ドライブへのコピーはしない）

## 重要な注意事項

- 既存アプリ（油屋・ほっかほっかカー）には**一切手を入れない**（読み取り専用）
- 写真はドライブにコピーしない
- アルバムリンクはスプレッドシートだけに置き、GitHubには書かない
- 起動処理は `window.onload` を待たない（過去の事故教訓）
